# Framio

**Framio** — быстрое, легковесное и функциональное Windows-приложение для создания скриншотов, длинных снимков с прокруткой, интерактивного аннотирования и плавной записи видео (MP4 H.264) и GIF-анимаций со звуком (WASAPI Loopback + микрофон).

Приложение разработано на Python 3.12, PyQt6, OpenCV и FFmpeg, выполнено в строгом темном Fluent-стиле и работает в полностью портативном режиме без внешних облачных зависимостей и телеметрии.

---

## Ключевые возможности

### 1. Скриншоты и длинные снимки (Scrolling Screenshot)
- **Захват области**: Выделение мышью любого участка экрана с поддержкой 8 маркеров изменения размера и перемещения рамки.
- **Одиночный хоткей Print Screen**: Мгновенный запуск захвата экрана по нажатию клавиши `Print Screen` (без обязательных модификаторов) с автоматическим подавлением встроенного инструмента «Ножницы» Windows.
- **Быстрый снимок всего экрана**: Нажатие комбинации сохраняет изображение всех подключенных мониторов сразу в файл и помещает в буфер обмена без открытия промежуточных рамок.
- **Длинный скриншот с авто-прокруткой**: Интеллектуальная склейка вертикальных веб-страниц, чатов и документов на базе субпиксельного сопоставления шаблонов `OpenCV matchTemplate` в реальном времени.
- **Прилипание к окнам (Window Snapping)**: Автоматическое определение геометрии открытых окон под курсором с извлечением нативных иконок приложений.
- **Форматы сохранения**: PNG (без потерь), JPEG (сжатый), WebP, DIB (растровый для мессенджеров), Base64 Data URI.

### 2. Студийная запись видео (MP4 H.264) и GIF
- **Высокая плавность (до 60+ FPS)**: Запись через аппаратный/оптимизированный конвейер FFmpeg libx264 (CRF 17, пресет veryfast/zerolatency).
- **Динамическое масштабирование рамки на лету**: Свободное сужение и расширение рамки записи в процессе захвата без искажения пропорций и без появления чёрных полос.
- **Запись звука без задержек**:
  - Системный звук (игры, видео, браузер) через нативный WASAPI loopback.
  - Голос с микрофона с авто-ресемплированием и сведением в чистую стерео-дорожку AAC.
  - Динамическое включение/отключение микрофона и динамиков прямо во время записи.
- **Премиальное качество GIF (FFmpeg PaletteGen)**: Двухпроходная генерация индивидуальной 256-цветной палитры и дизеринг Bayer. Никаких «грязных» цветов и артефактов.
- **Изолированный захват окна**: Возможность привязать запись к конкретному окну даже при перекрытии его другими приложениями.

### 3. Интерактивное рисование и цензура (в том числе во время видео)
- **Живое рисование поверх видео**: Включение панели рисования прямо в процессе видеозаписи с возможностью впекания аннотаций в итоговый видеофайл.
- **Режим «Неосязаемая рамка»**: Позволяет кликать и работать в приложениях/играх под рамкой, а при необходимости рисования — мгновенно активировать перехват кликов.
- **Закрепление аннотаций (Pin)**: Закрепленные пометки остаются на экране при перемещении рамки, а незакрепленные перемещаются синхронно с областью записи.
- **Векторные инструменты**:
  - Стрелки с усиками (Barbed arrow), классические, двойные и пунктирные.
  - Карандаш с плавным сглаживанием линий.
  - Прямоугольники и эллипсы (с заливкой и без).
  - Текст с контрастным полупрозрачным фоном для идеальной читаемости на любом фоне.
  - Пошаговые номерные маркеры (1, 2, 3...) для создания инструкций.
- **Цензура личных данных (Мозаика и Блюр)**:
  - Моментальное переключение между мозаичным пикселированием и мягким размытием по Гауссу.
  - Настраиваемый размер зерна и радиус блюра с палитрой подложки.
- **Интерактивное управление слоями**:
  - Перемещение любой созданной фигуры правой кнопкой мыши (ПКМ-drag).
  - Редактирование цвета, толщины, порядка наложения (Z-order) и дублирование (`Ctrl+D`).

### 4. Удобство, портативность и настройки
- **Полная портативность (Portable Mode)**: Настройки хранятся в `settings.json` рядом с программой, а скриншоты, видео и GIF по умолчанию сохраняются в подпапки каталога `Captures/`. При переносе папки на другой диск пути обновляются автоматически.
- **Двуязычный интерфейс (i18n)**: Автоматическое определение языка системы с полной поддержкой русского и английского языков (переключается в настройках).
- **Сворачивание в трей и автозапуск**: Тихое нативное присутствие в панели задач Windows с управлением через контекстное меню.

## Горячие клавиши по умолчанию

| Действие | Комбинация | Описание |
| :--- | :--- | :--- |
| **Захват области (скриншот)** | `Print Screen` | Затемняет экран и открывает рамку выделения |
| **Быстрый скриншот экрана** | `Ctrl + Shift + Print Screen` | Мгновенно сохраняет все экраны в файл и буфер |
| **Запись всего экрана (видео)** | `Ctrl + Shift + F9` | Запуск полноэкранной видеозаписи со звуком |
| **Остановка записи** | `Ctrl + Shift + F10` | Завершает активную запись видео или GIF |
| **Копировать в буфер** | `Ctrl + C` | Копирует снимок в выбранном формате |
| **Сохранить на диск** | `Ctrl + S` | Сохраняет в файл с диалогом выбора |
| **Отмена действия (Undo)** | `Ctrl + Z` | Отменяет последнюю нарисованную фигуру |
| **Повтор действия (Redo)** | `Ctrl + Y` | Возвращает отмененное действие |
| **Дублировать фигуру** | `Ctrl + D` | Клонирует выделенную фигуру со сдвигом |
| **Удалить фигуру** | `Delete` | Удаляет фигуру под курсором |
| **Закрыть / Отмена** | `Escape` | Закрывает рамку или отменяет запись |

*Все комбинации настраиваются во вкладке «Горячие клавиши» диалога настроек.*

## Запуск приложения

### Портативная сборка Windows (.exe)
1. Запустите ярлык **`Start_Framio.bat`** в корне репозитория или исполняемый файл **`dist/Framio/Framio.exe`**.
2. Приложение появится в системном трее и будет готово к работе по нажатию клавиши `Print Screen`.

### Запуск из исходного кода
```bash
# Установка зависимостей
pip install -r requirements.txt

# Фоновый запуск без консоли
run.bat

# Или запуск через Python
python main.py
```

### Запуск тестов
```bash
python -u tests/test_components.py
```

## Сборка автономного дистрибутива

Сборка нативного переносимого пакета Windows выполняется через PyInstaller с конфигурацией `Framio.spec`:
```bash
python -m PyInstaller --noconfirm Framio.spec
```
Готовая сборка размещается в каталоге `dist/Framio/`.
