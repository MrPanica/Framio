# Framio Development & Versioning Guidelines for AI Agents

Данный файл содержит обязательные правила для AI-ассистентов (Antigravity, Cursor, Copilot, Codex и др.) при разработке и поддержке проекта Framio.

---

## 1. Синхронизация версий и документации (ОБЯЗАТЕЛЬНОЕ ПРАВИЛО)

Каждый раз, когда в проекте обновляется/повышается версия (например, в файле `VERSION`), агент **ОБЯЗАН В ТОМ ЖЕ КОММИТЕ** синхронно обновить:

1. **`VERSION`**:
   - Содержит точный номер версии (например, `1.0.18\n`).

2. **`CHANGELOG.md`**:
   - Добавить блок нового релиза в самом верху: `## [X.Y.Z] - YYYY-MM-DD`.
   - Обязательно предоставить описание изменений на двух языках: `### English` и `### Русский`.
   - Описывать конкретные изменения простым и понятным языком.

3. **`README.md` (Обязательная актуализация)**:
   - **Всегда** обновлять номер текущей версии в начале документа:
     - В секции English: `The current release is \`X.Y.Z\`. See [CHANGELOG.md](CHANGELOG.md) for the release history.`
     - В секции Русский: `Текущая версия — \`X.Y.Z\`. История изменений находится в [CHANGELOG.md](CHANGELOG.md).`
   - Актуализировать таблицы горячих клавиш по умолчанию (Default hotkeys), если менялись комбинации или настройки по умолчанию.
   - Синхронизировать описания новых функций и инструментов, не допуская расхождения между кодом и документацией.

---

## 2. Кодировка и форматирование

- **Кодировка UTF-8**: Все файлы с русским текстом (исходный код, конфиги, документация) должны сохраняться строго в кодировке UTF-8 без повреждений (mojibake).
- **Стиль ответов и кода**: Не использовать эмодзи в ответах, коде или коммитах.
- **Окончание задачи**: По завершении задачи включать в финальный ответ фразу «Задача завершена».

---

## 3. Тестирование и сборка

1. **Запуск тестов**:
   Перед любым коммитом обязателен прогон всех тестов:
   ```powershell
   pytest tests/test_components.py
   # или
   python -u tests/test_components.py
   ```

2. **Локальная сборка**:
   Перед релизом или push в репозиторий выполнить компиляцию:
   ```powershell
   python -m PyInstaller Framio.spec --noconfirm
   python -m PyInstaller Framio-onefile.spec --noconfirm
   Copy-Item -Force "dist\Framio.exe" "dist-onefile\Framio.exe"
   ```

3. **Релиз**:
   - Создавать аннотированный тег `vX.Y.Z`.
   - Отправлять ветку `main` и тег в GitHub: `git push origin main && git push origin vX.Y.Z`.
   - Отслеживать успешное завершение сборки GitHub Actions.
